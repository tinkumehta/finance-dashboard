# 📊 Project Overview
A modern, responsive finance dashboard application built with React that allows users to track their financial activities, visualize spending patterns, and manage transactions with role-based access control. The application features a clean UI with dark mode support, data persistence, and comprehensive transaction management capabilities.


## ✨ Features
Dashboard Overview
Summary Cards: Display total balance, income, and expenses with visual indicators

Balance Trend: Interactive line chart showing balance changes over time

Spending Breakdown: Pie chart visualization of expenses by category

Key Insights: Smart analytics including highest spending category, monthly averages, and savings rate

Transaction Management
Complete Transaction List: View all transactions with date, description, category, and amount

Search Functionality: Filter transactions by description or category

Type Filtering: Toggle between income and expense transactions

Sorting: Sort transactions by amount (ascending/descending)

Export Feature: Export transactions to JSON format

## Role-Based Access Control
Viewer Role: Read-only access to view all data

Admin Role: Full CRUD operations (Add, Edit, Delete transactions)

Role Switching: Easy role toggle in the header

User Experience
Dark Mode: Toggle between light and dark themes with persistence

Responsive Design: Optimized for desktop, tablet, and mobile devices

Data Persistence: Automatic saving to localStorage

Smooth Animations: Enhanced visual feedback and transitions

## 🚀 Tech Stack
Frontend Framework: React 18

Build Tool: Vite

Styling: CSS Modules with CSS Variables

Icons: Lucide React

State Management: React Context API

Data Persistence: LocalStorage API
